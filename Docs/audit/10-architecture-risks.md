# 10 — Architecture & Technical Risk Register

**Verification Status:** `VERIFIED` (Every risk entry is backed by direct code evidence, exact file paths, and line numbers)

---

## 1. Prioritization Framework

- **`P0 — Critical`:** Verified serious security vulnerabilities, data corruption, or hard blockers to core existing workflows.
- **`P1 — Foundation`:** Cross-cutting architectural defects, broken integrations, ownership gaps, and mobile layout blockers affecting multiple modules.
- **`P2 — Product Completion`:** Feature-level bugs, missing validations, cache invalidation gaps, dead UI buttons, and responsive polish needed for a coherent Coach & Member product.
- **`P3 — Product Expansion`:** Architectural limitations that will cause rework when introducing Gym Owner, multi-tenancy, memberships, and billing.
- **`P4 — Advanced`:** Readiness gaps for AI insights and advanced telemetry.
